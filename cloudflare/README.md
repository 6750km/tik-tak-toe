# Cloudflare website infrastructure

- `site/` contains the public `kiki-apps.uk` Pages project, page copy, support form, D1 schema, and protected message view.
- `email-worker/` contains the notification Worker and the plain-text/HTML email templates.
- `supabase-email-templates/` contains the production-ready Confirm Signup and Reset Password templates plus restoration instructions.

See `site/README.md` for resource names and restoration instructions.
